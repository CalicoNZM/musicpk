# contributing

this is a small community wiki, not a product. if you want to help, cool.

**how i work:**
- open an issue first if it's big — i check them in the evenings
- keep the human-music rule. no AI tracks, no exceptions
- wiki edits should have a source or say where you got it — `personal collection`, `liner notes`, `interview from 2004` is fine
- don't re-upload stuff you don't own. if you're not sure, ask in a genre thread

**dev:**
```
python3 py_server.py
# http://localhost:3000
# public/ is the frontend, py_server.py is the whole backend
```
no build step, no npm needed unless you touch the old `server.js` path.

**what needs help:**
- better search (right now it's just LIKE %query%)
- cover upload vs URL
- making the iTunes/Spotify import less janky for Spotify albums

just keep it human. no 3-card feature sections in PR descriptions, no purple gradients.
